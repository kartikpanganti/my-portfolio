## Kartik Panganti Portfolio

This is a dynamic, responsive developer portfolio built with React, Vite, and Tailwind CSS. It features:

- **Dynamic Sections:** Showcases your skills, projects, certifications, achievements, education, and work experience.
- **Performance Optimized:** Fast load times, reduced animation blocking, and optimized assets.
- **Dark/Light Mode:** Theme switcher with persistent mode (remembers your choice after refresh).
- **Interactive UI:** Modern animations, hover effects, and engaging transitions.
- **Security Meta Tags:** Enhanced security for GitHub Pages deployment.
- **Contact Form:** Integrated with reCAPTCHA and EmailJS for secure messaging.
- **Mobile Friendly:** Fully responsive for all devices.

View the live site at: [kartikpanganti.me](https://kartikpanganti.me)
